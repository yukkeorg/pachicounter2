# 初当たり確率の分母規則が機種ごとに違うのは仕様である

5 つの機種プラグインは「どの回転を通常時回転数に算入するか」がそれぞれ違う。`uforush` は
電サポが切れた時点の未消化回転をまとめて算入し、`ghostneo` は同じ処理を「100 回転を完走した
ときだけ」に限定し、`stealth` は算入しない。これはバグではなく、**統一してはならない**。

理由は、台が出す電サポ信号からは「玉が減らない状態にいる」ことしか分からず、その区間が
高確率（確変・ST）なのか通常確率（時短）なのかが判別できないため（配線資料上の出力内容は
一貫して「大当り中、高ベース中に出力」であり、大当り中も同時に ON になる）。通常確率で
抽選された回転だけが初当たり確率の分母に入る資格を持つので、区間の性質を知っている機種
プラグインだけがこの判定を下せる。

したがって語彙は統一するが（通常時回転数＝通常確率で抽選された回転の累計）、判定は機種
プラグインの責務とする。同じ理由で、共通スキーマの `first_hits` に何を入れるかもプラグインの
判断に委ねる（`xfiles` は出玉あり大当りの回数をそのまま入れる。これは意図的である）。
