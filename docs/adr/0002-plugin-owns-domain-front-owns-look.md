# 機種プラグインはドメインを持ち、フロントは見た目だけを持つ

旧実装の機種プラグインは `build()` の中で Pango markup・色値・SVG フレームのパスまで組み立てて
いた（`uforush.py:110-146`）。これはフロントを差し替えるたびに markup と SVG スロットの意味を
再実装させることになり、複数フロントを同時に生かすという構成の目的と衝突する。

そこで境界を「機種プラグイン＝信号の意味・カウンタ規則・状態遷移・**機種固有の呼び名**まで」、
「フロント＝色・書体・配置・装飾だけ」と引いた。「UFO RUSH」「XTRA-RUSH」といった呼び名を
ドメイン側に置くのは、フロントを 2 つ書いたときに同じ文言を 2 箇所に書かせないため。
機種ごとの状態は共通の enum（`normal`/`bonus`/`kakuhen`/`jitan`）と機種語彙のラベルの組で表す。

機種固有の数値は `{key, label, value, unit}` のラベル付きメトリクス列として渡す。これにより
機種を知らない汎用フロントでも、並べるだけで新機種に対応できる。
